# Gateway Simulator

A payment gateway simulator built with **NestJS** using **npm**.

This project simulates a traditional payment gateway supporting:

- Credit Card
- Pix
- Boleto

It is designed for local development, integration testing, and payment flow simulation without relying on real providers.

---

##  Purpose

The goal of this application is to provide a controlled environment to simulate payment transactions.

It returns predefined responses for:

- Approved payments
- Refused payments
- Pending payments
- Processing errors

This allows frontend and backend systems to be tested safely and predictably.

---

## 🛠 Tech Stack

- Node.js
- NestJS
- TypeScript
- npm
